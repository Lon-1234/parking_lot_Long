## 测试准备

1. `npm install && npm run dev`，保持 `VITE_USE_MOCK=true`。
2. 页脚点击“重置 Mock 数据”。
3. 三个账号分别验证：`user / 123456`、`operator / 123456`、`admin / 123456`。
4. 每个用例记录浏览器、时间、实际结果和截图/缺陷号；未执行的条目不得改成通过。
